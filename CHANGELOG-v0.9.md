# Изменения v0.9 — административная панель

- Добавлена SQLAdmin-панель `/admin` с авторизацией через сессию и отдельным паролем.
- Панель не монтируется без `ADMIN_PASSWORD` и `ADMIN_SESSION_SECRET` (не менее 32 символов).
- Доступен просмотр источников, сообщений, черновиков, каталога, сеансов, цен и аудита.
- Через SQLAdmin можно добавлять и отключать источники и редактировать JSON извлечённых данных черновика.
- Публикации, сеансы, цены, исходные сообщения и журнал аудита в панели доступны **только для чтения**.
- Проверка исходных сообщений и публикация черновика выполняются через существующий защищённый API. Полноценный workflow модерации в UI пока не готов.

## Запуск

1. Заполнить `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET` (случайный секрет длиной от 32 символов), `ADMIN_API_KEY`.
2. `docker compose up --build -d`.
3. Открыть `http://127.0.0.1:8000/admin` локально.

**Безопасность:** не выставляйте панель в интернет по HTTP. Перед внешним доступом необходим TLS reverse proxy, защищённые cookie, rate limiting логина, CSRF-проверки и проверка управления сессиями. Для production также нужны RBAC и аудит редактирования черновиков: сейчас SQLAdmin редактирует их непосредственно.

## Статус проверки

- 30 локальных unit/static тестов проходят.
- Синтаксис Python проверен.
- Сам SQLAdmin в текущем окружении не установлен, поэтому его runtime-подключение, формы и сессии не проверены.
- Docker Compose и PostgreSQL-интеграция не проверены.
