# Изменения v0.8

- `CatalogDraft` и миграция `0007_catalog_drafts`.
- Консервативное извлечение названия, цены и подсказок даты/времени из исходных сообщений.
- Сравнение заголовков с опубликованными карточками для выявления возможных дублей.
- API создания и просмотра черновиков и отдельная ручная публикация с валидацией `PublishIn`.
- Непроверенные сообщения не публикуются автоматически.

## Ограничения

- Это эвристический парсер, не LLM extraction: даты без года остаются подсказками, а не готовыми временными интервалами.
- Поиск дублей по названию не заменяет семантическую дедупликацию.
- SQLAdmin, полноценные ingestion job и интеграционные тесты PostgreSQL ещё не готовы.
