# 💘 Web-чат агента «Свидание-консъерж»

Красивый React-интерфейс поверх агентного ядра (`app/core`) — тот же агент,
что и в Telegram-боте, но через HTTP-адаптер. Никакого Telegram не требуется.

## Запуск (два терминала)

```bash
# 1) API с агентом (из корня проекта)
../../.venv/bin/uvicorn app.main:app --reload --port 8000

# 2) Фронтенд (из этой папки)
npm install && npm run dev
# → http://localhost:5173
```

## Как это устроено

- Бэкенд: `app/web_chat.py` — REST-эндпоинты `/api/chat/{id}/messages|actions|history|reset`.
  Агент, сессия и инструменты — из `app/core/`, транспорт — `InMemoryTransport`.
- Каталог в демо-режиме фейковый (`DemoCatalogTool`); при подключённом PostgreSQL
  замените его на `app.core.tools.SearchCatalogTool` в `build_agent()` — больше
  ничего менять не нужно, ядро то же.
- Карточки рендерятся в HTML на бэкенде (`app/core/rendering.py`) с полным
  экранированием значений; фронтенд доверяет только этому проверенному рендеру.
- Реакции 👍/🚫 в web-MVP фиксируются как события; постоянные запреты с
  delivery-токенами остаются в Telegram-адаптере.

## Что красивого

- Тёмная тема с розово-закатным градиентом, стеклянные панели
- Пузыри сообщений с аватаром 💘, typing-индикатор «сердцебиение»
- Инлайн-кнопки действий (ослабить условие, другие варианты)
- Примеры запросов чипами, авто-скролл, история в localStorage
