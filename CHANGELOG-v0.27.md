# v0.27 — кнопки ослабления условия (FR-08) и backoff источников (FR-12)

## FR-08 / UC-06: пустая выдача с кнопкой изменения одного условия

Приёмка спеки: «Кнопка меняет только выбранное условие», ослабление — только после согласия.

- При пустой выдаче бот предлагает кнопки только по тем явным условиям, которые задал пользователь: район, метро, бюджет, indoor, время. Замысел запроса (query) никогда не ослабляется и не переписывается.
- `relax:<field>` callback валиден только для поля из `_relax_offers` текущего поколения диалога; невалидный callback не меняет состояние (поколение не растёт).
- `apply_relax` снимает ровно одно условие и связанные слоты (бюджет — вместе с исходной единицей и provenance), очищает `_shown_current` и счётчик уточнений, после чего запускается новый поиск в новом поколении.
- Разметка хранится в `telegram_outbox.reply_markup` (миграция `0018`) и отправляется воркером только для сообщений без карточек.
- Аналитика: событие `condition_relaxed` (+field) — можно мерить, какие условия чаще мешают выбору.

## FR-12: ограниченные повторы и backoff источников

Приёмка спеки: «Ограниченные повторы, backoff, …», «Ошибка одного источника не блокирует остальные».

- `TelegramSource.consecutive_errors` и `next_attempt_at` (миграция `0018`).
- Экспоненциальный backoff: 60 с → 120 с → 240 с …, максимум 1 час; успех сбрасывает счётчик и таймер.
- `sync_sources` пропускает источники на backoff (`skipped_backoff` в статистике), остальные продолжают работу.
- Старые тесты Telethon-приёмки дополнены новыми полями без изменения поведения.
