# v0.29 — красивая UI-обертка: HTML-карточки и web-чат на React

## UI-полировка карточек (Telegram + web)

- Новый рендер `app/core/rendering.py`: HTML-карточки с жирным заголовком,
  эмодзи-навигацией (📍 адрес, 💰 цена, 🕒 сеанс, ✅ причина). NFR-10 соблюдён:
  смысл не зависит от эмодзи, все факты продублированы словами.
- **Безопасность разметки**: все динамические значения экранируются
  `html.escape` — текст источника не может внедрить теги; покрыто негативным
  тестом с `<script>` в заголовке и описании.
- `telegram_outbox.parse_mode` (миграция `0019`): 'HTML' для карточек,
  None для унаследованных простых сообщений. Sender worker и Telegram-адаптер
  передают parse_mode в Telegram API.

## 💘 Web-чат на React (переезд из Telegram — теперь с лицом)

- Бэкенд `app/web_chat.py`: REST `/api/chat/{id}/messages|actions|history|reset`
  поверх агентного ядра (`app.core`) с `InMemoryTransport`; демо-каталог
  работает без PostgreSQL, заменяется на `SearchCatalogTool` одной строкой.
- CORS для dev-фронтенда; эндпоинт `/api/chat/health`.
- Фронтенд `web/` (Vite + React): тёмная тема с закатным градиентом, пузыри с
  аватаром 💘, typing-индикатор, инлайн-кнопки действий (relax/more/like),
  чипы-примеры запросов, история в localStorage, авто-скролл.
- Фронтенд доверяет только проверенному рендеру ядра: HTML экранируется на
  бэкенде, на клиенте восстанавливаются лишь `<b>`/`<i>` из нашего формата.
- Проверено живым прогоном: uvicorn + curl — карточка с кнопками приходит,
  `npm run build` собирается без ошибок.
