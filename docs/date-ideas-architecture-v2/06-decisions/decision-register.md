# Реестр архитектурных решений

## Утверждённые направления
- Модульный монолит FastAPI и PostgreSQL с FTS/pgvector вместо микросервисов.
- SQLAdmin для ручной модерации.
- Ограниченная Python FSM с LLM для извлечения смысловых параметров.
- Неизменяемые опубликованные версии и ручной контроль качества каталога.
- Явные постоянные предпочтения отдельно от поведенческой истории.
- Рекомендация на уровне конкретного сеанса/предложения.
- `generation_id` для защиты от устаревших асинхронных результатов.
- Inbox/Outbox с учётом неоднозначного ответа Telegram.

## Требуют решения
| Вопрос | Статус | Критерий выбора |
|---|---|---|
| Погодные ограничения FR-07 | Открыт | Источник, география, допустимая устарелость |
| Embedding-модель | Открыт | Качество на русскоязычном eval, размер и latency |
| Размер retrieval pool и веса reranking | Открыт | Офлайн-оценка и реальные реакции |
| Окна верификации | Открыт | Риск устаревания по типам фактов |
| Административная аутентификация | Открыт | Роли, сессии, CSRF, аудит |
| Политика повторов неоднозначной отправки | Открыт | Допустимый риск дублей |
| Хранение и резервное копирование | Открыт | Правовые требования, RPO/RTO |
| Производительность | Открыт | Нагрузочные тесты и продуктовые SLO |

Не считать открытые решения уже реализованными или протестированными.
