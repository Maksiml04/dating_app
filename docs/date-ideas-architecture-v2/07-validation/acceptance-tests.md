# Приёмочные сценарии архитектуры

| № | Сценарий | Ожидаемый результат |
|---|---|---|
| AT-01 | Жёсткий бюджет ниже цены предложения | Предложение исключено |
| AT-02 | Цена неизвестна, бюджет жёсткий | Предложение исключено |
| AT-03 | Пять сеансов одного события | Не занимают все три позиции |
| AT-04 | Сеанс не попадает в выбранное время | Не выдаётся |
| AT-05 | Пользователь меняет бюджет во время поиска | Старая генерация не отправляется |
| AT-06 | Повтор Telegram update | Одна логическая обработка |
| AT-07 | Два одновременных сообщения одного чата | Последовательная обработка |
| AT-08 | Публикация отозвана после формирования плана | Sender блокирует отправку |
| AT-09 | Истёк TTL Outbox | Сообщение не отправляется |
| AT-10 | Ответ Telegram потерян после принятия | Статус ambiguous, не ложная гарантия доставки |
| AT-11 | Векторный поиск недоступен | Корректный FTS-only fallback |
| AT-12 | LLM недоступна | Управляемый диалог без выдуманных фактов |
| AT-13 | Объединение canonical-алиасов | Нет циклов и повторов |
| AT-14 | Изменение черновика | Опубликованная версия неизменна |
| AT-15 | Удалённое сообщение источника | Явный статус, а не молчаливое удаление |
| AT-16 | Отказ аналитики | Пользовательский ответ не блокируется |

Это **проектные сценарии**; автоматизированные тесты пока не запускались.
