# Parser — получение данных из источников

Telethon читает разрешённые Telegram-источники, сохраняет исходный текст и медиа с указанием происхождения. Повторное чтение одного сообщения идемпотентно. Извлечение сущностей формирует черновики, но не публикует их автоматически.

## Обработка изменений
Редактирование источника создаёт новую ревизию. Удаление, недоступность и временная ошибка различаются: `deleted`, `inaccessible`, `retryable_error`. Исчезновение из выборки не означает доказанное удаление.

## Надёжность
Контроль лимитов Telegram, ограниченные повторы с задержкой, checkpoint по источнику, дедупликация по source/message ID, наблюдаемость ошибок и ручная повторная обработка.

## Защита
Внешний текст считается недоверенным: он не может отдавать инструкции LLM, управлять публикацией или изменять системные правила. Права доступа к источникам проверяются отдельно.
