# Analytics — события и метрики

События: поступление запроса, нормализация условий, поиск, кандидаты, создание плана отправки, подтверждение/неоднозначность доставки, показ, реакция, отказ и ошибка. У каждого события есть ID, timestamp, request ID, generation ID и версия алгоритма при необходимости.

## Метрики
Покрытие каталога, доля запросов с тремя валидными вариантами, latency p50/p95, число уточнений, доля повторов, качество обратной связи, стоимость LLM и ingestion, ошибки Telegram и задержка индексации.

## Принципы
Не считать повторную доставку новым уникальным показом. Отличать отсутствие реакции от отрицательной оценки. Аналитика не должна блокировать пользовательский ответ.
