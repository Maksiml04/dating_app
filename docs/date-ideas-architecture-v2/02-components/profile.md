# User Profile Service — предпочтения пользователя

Постоянные предпочтения записываются **только по явной просьбе пользователя**. История просмотров, кликов и реакций хранится отдельно как поведенческие сигналы для мягкого ранжирования и не превращается автоматически в жёсткие запреты.

## Приоритет
Явное условие текущего запроса → явное сохранённое предпочтение → контекст текущего диалога → мягкие поведенческие сигналы. Пользователь может изменить или удалить сохранённые предпочтения.

## Данные
Идентификатор пользователя Telegram связывается с внутренним ID. Для каждой постоянной настройки нужны происхождение, время изменения и возможность удаления. История показов должна хранить canonical ID и конкретный показанный вариант, чтобы корректно избегать повторов.

## Приватность
Минимизировать персональные данные, установить сроки хранения, реализовать удаление и разграничение доступа в админке.
