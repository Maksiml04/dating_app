# Admin — административный интерфейс

SQLAdmin работает внутри FastAPI, без отдельного React-приложения. Доступ возможен только после аутентификации и проверки ролей; требуется CSRF-защита и журнал аудита.

## Основные операции
Просмотр очереди черновиков, исходных доказательств, различий между ревизиями, объединение дублей, публикация, отзыв публикации, архивация, запуск перепроверки, просмотр проблем индексации и доставки.

## Ограничения
Нельзя изменять опубликованный снимок напрямую. Каждое действие фиксирует администратора, время, объект, прежнее и новое состояние. Массовые действия требуют явного подтверждения.

## Открытый вопрос
Способ входа и модель ролей необходимо утвердить до публичного развёртывания.
