# Worker — фоновые операции

Фоновые задания: извлечение данных, нормализация, дедупликация, индексация, перепроверка, доставка и служебная очистка. Общий механизм выполнения может обслуживать разные типы задач, но доменные состояния сохраняются отдельно.

## Гарантии
У задания есть ID, тип, payload-версия, статус, число попыток, дедлайн и ключ идемпотентности. Получение задания защищено от конкурентного выполнения; зависшие задания можно безопасно перезапустить.

## Ошибки
Повторяются только временные сбои, с backoff и ограничением попыток. Невалидные payload и постоянные ошибки отправляются в журнал проблем для ручного разбора. Нужны метрики глубины очереди, возраста старейшего задания и ошибок.
