# Изменения v0.7

- Добавлены TelegramSource и SourceMessage, миграция 0006.
- Реализованы идемпотентное сохранение сообщений и хеш нормализованного текста.
- Добавлены API регистрации источника и ручной проверки входящих публикаций.
- Реализован запускаемый вручную Telethon-адаптер синхронизации.
- Непроверенные записи никогда не публикуются автоматически.

## Ограничения

- Автоматическая нормализация в Place/Event/Occurrence/Offer и семантическая дедупликация пока отсутствуют.
- Модерация пока через защищённые API, SQLAdmin ещё не подключён.
- Для Telethon нужны API ID, API HASH и авторизованная session.
- Синхронизация каналов пока запускается вручную; расписание, backoff и обновления отредактированных сообщений не реализованы.
- Интеграционный запуск с Telegram и PostgreSQL не проверен.
