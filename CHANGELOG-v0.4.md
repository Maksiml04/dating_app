# v0.4 — обратная связь Telegram и явная память

- Inline-кнопки 👍/👎 для каждой из трёх карточек в Telegram Outbox sender.
- Обработка `callback_query` в общем webhook с Inbox-дедупликацией `update_id`.
- Проверка факта отправки (`Impression`) перед записью отзыва.
- Уникальный `callback_id` предотвращает повторную запись одного отзыва.
- Команды `/remember ...` и `/forget` для явного управления постоянными предпочтениями.
- Миграция 0004 и модульные тесты.

## Ограничения

- Telegram `answerCallbackQuery` пока не вызывается: после нажатия может сохраняться индикатор ожидания.
- Уточняющие вопросы, полноценный FSM и асинхронная обработка поиска не завершены.
- Реальный Docker/PostgreSQL/Telegram E2E не проверен.
- Отзывы пока не участвуют в reranking; данные сохраняются для следующего этапа.
