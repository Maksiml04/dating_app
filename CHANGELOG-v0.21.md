# v0.21 — проверяемое чтение Telegram каналов

- Новый `python -m app.telethon_ingest probe --channel @username --limit 5`: получает настоящие Telegram-сообщения через Telethon без PostgreSQL и без изменений чекпойнта.
- `login`: разовая интерактивная авторизация; `probe` и `sync` никогда не запрашивают код входа.
- `sync --limit N`: ограничивает загрузку, печатает счётчики по каналам; ранее пустая история при старте с `reverse=True` могла приводить к загрузке старейших постов вместо последних.
- Каналы разрешаются по username; проверяется соответствие Telegram ID сконфигурированному `telegram_source.channel_id`.
- Счётчик позиции чтения увеличивается и после сообщений без текста. Ошибка одного канала не мешает обработке остальных.
- Добавлены 15 модульных тестов с имитацией MTProto и инструкция `TELEGRAM_PARSER_CHECK.md`.

**Ограничение:** в этой среде нет действующей Telethon-сессии/API-ключей, поэтому фактическое подключение к Telegram не подтверждено. PostgreSQL и Docker E2E также не выполнялись.
